# TP03-PHP-BENRAHMA-ANAS
TP 03 PHP — Programmation Web 2 — 2026/2027`
TP 3 PHP — Suivi des notes des apprenants
1. Présentation du projet

Ce projet consiste à développer une mini-application web en PHP permettant de saisir, enregistrer, afficher et analyser les notes des apprenants d'une classe.

Ce TP a pour objectif de mettre en pratique les bases du langage PHP ainsi que la manipulation des formulaires HTML et des fichiers.

2. Objectifs pédagogiques
Manipuler les variables, les constantes et les types de données.
Utiliser les conditions (if, elseif, else, switch).
Maîtriser les boucles (for, while, do-while, foreach).
Créer, afficher, trier et analyser des tableaux.
Traiter les formulaires HTML avec GET et POST.
Réutiliser du code avec include et require.
Lire et écrire des fichiers CSV et JSON.
Utiliser les sessions, les cookies et les redirections.
Manipuler et valider les dates en PHP.

5. Installation et exécution
Installer PHP et Visual Studio Code.

Ouvrir le terminal intégré.

Lancer le serveur PHP :

Ouvrir le navigateur à l'adresse :
